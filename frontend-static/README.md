# Frontend Static

Subproject ini dibuat khusus untuk demo frontend statis tanpa backend.

## Route

- `/` menampilkan landing page
- `/login` menampilkan login page statis

## Vercel

Saat membuat project di Vercel:

1. pilih repository ini
2. set `Root Directory` ke `frontend-static`
3. framework akan terdeteksi sebagai `Vite`
4. deploy

Landing page di folder ini mengikuti tampilan landing page utama proyek, dan tombol login mengarah ke halaman login statis.
