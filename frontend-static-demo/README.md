# Frontend Static Demo

Folder ini berisi landing page dan login page statis yang siap dipakai untuk demo di Vercel.

## Isi folder

- `index.html`: landing page demo
- `login.html`: login page demo
- `styles.css`: styling utama
- `script.js`: interaksi ringan untuk menu dan login demo
- `vercel.json`: routing agar `/` dan `/login` berjalan rapi di Vercel
- `assets/`: logo dan gambar pendukung

## Deploy ke Vercel

1. Import repository ini ke Vercel.
2. Saat diminta pengaturan project, set `Root Directory` ke `frontend-static-demo`.
3. Framework preset bisa dibiarkan `Other`.
4. Build command dan output directory tidak perlu diisi.
5. Deploy.

## Route demo

- `/` untuk landing page
- `/login` untuk login page
